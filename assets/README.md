# mayfly assets

Brand assets for the mayfly CLI and project documentation.

## Files

| Asset | Use |
| --- | --- |
| `mayfly-mark.svg` | Primary mark on light backgrounds |
| `mayfly-mark-mono.svg` | Single-color and print contexts; set `color` or replace `currentColor` |
| `mayfly-logo.svg` | Horizontal logo and wordmark |
| `mayfly-social.svg` | 1200x630 link previews and release pages |

All files are SVG so they remain sharp at CLI documentation, package-page, and social-preview sizes. The artwork uses no external fonts, images, or runtime dependencies.

## Palette

- Ink: `#101820`
- Teal: `#16B8A6` to `#087F8C`
- Signal yellow: `#F7C948`
- Soft white: `#F5F8FA`
- Muted blue-gray: `#9CB5BF`

The mark combines a four-wing geometric silhouette with a central flight path. The yellow center is the finite completion signal: one task, then gone.
